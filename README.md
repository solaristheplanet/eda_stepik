# Датасет Abalone

Датасет содержит физические измерения морских ушек (abalone) и их возраст, оценённый по количеству колец на раковине. Используется для задач регрессии (предсказание возраста) и классификации (например, по полу).

## Источник

Ссылка: https://raw.githubusercontent.com/aiedu-courses/eda_and_dev_tools/refs/heads/main/datasets/abalone.csv

## Описание задачи

Основная задача — предсказать возраст моллюска (`Rings`) по его физическим характеристикам.  
Возраст в годах приблизительно равен `Rings + 1.5`.

Также можно решать вспомогательные задачи:
- классификация по полу (`Sex`: M, F, I);
- анализ влияния пола и размера на возраст;
- отбор и интерпретация признаков для регрессии.

## Структура данных

| Колонка | Тип | Описание |
| --- | --- | --- |
| `Sex` | категориальная | Пол: `M` (male), `F` (female), `I` (infant) |
| `Length` | числовая | Длина раковины (в мм) |
| `Diameter` | числовая | Диаметр раковины (в мм) |
| `Height` | числовая | Высота с мясом (в мм) |
| `Whole weight` | числовая | Полный вес (в граммах) |
| `Shucked weight` | числовая | Вес мяса (в граммах) |
| `Viscera weight` | числовая | Вес внутренностей (в граммах) |
| `Shell weight` | числовая | Вес раковины после сушки (в граммах) |
| `Rings` | числовая (целая) | Количество колец на срезе раковины — целевая переменная (возраст) |
